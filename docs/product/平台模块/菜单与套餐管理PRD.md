# B 端菜单与套餐管理设计文档

## 1. 概述

### 1.1 目标
为平台管理员提供菜单与套餐维护能力，支持排序、预览、发布控制和操作追溯。

### 1.2 范围

| 类型 | 可见对象 | 可见条件 |
|---|---|---|
| 平台菜单 | 平台成员 | 启用 + 角色授权 |
| 租户菜单 | 企业成员 | 启用 + 套餐包含 + 角色授权 |

约束：企业管理员**不能**自定义本企业的菜单名称和顺序，租户菜单结构全局唯一。

## 2. 页面结构

- 菜单管理
  - 平台菜单：结构与排序
  - 租户菜单：结构与排序、套餐配置
- 审计日志

## 3. 菜单维护

### 3.1 布局
菜单树、属性表单、实时预览联动。宽屏三栏，窄屏上下排列。

### 3.2 结构与属性
- 层级：目录 → 页面，建议最多 2～3 级。
- 属性：名称、图标、路由、上级目录、启用状态、权限标识。
- 按钮权限作为页面的权限点维护，不进入导航树。
- 菜单标识创建后不可修改、不可复用。

### 3.3 排序
- 支持拖拽：插到前面、插到后面、移入目录。
- 提供上移、下移、选择上级目录，用于长列表、触屏和键盘操作。
- 非法位置不可放置。

### 3.4 预览
- 平台菜单按角色预览。
- 租户菜单按套餐组合和角色预览。
- 复用线上导航组件；停用项及无可见子项的目录不显示。

### 3.5 发布
- 改动先存草稿，支持撤销和放弃修改。
- 发布前展示改动清单和影响范围。
- 建议支持版本记录与回滚；回滚同样需通过引用校验。
- 保存和发布时校验版本号，防止多人覆盖。

### 3.6 保护规则
系统保护菜单（如菜单管理、审计日志）和必含菜单（如首页、角色权限）不可停用或删除。

## 4. 菜单删除

| 情况 | 处理 |
|---|---|
| 系统保护项、必含菜单 | 禁止 |
| 目录下有未删除子项 | 禁止，先移走或删除子项 |
| 被已发布套餐引用 | 禁止，先移除引用并发布套餐变更 |
| 被有存量企业的已下架套餐引用 | 禁止 |
| 仅被未发布套餐或无存量的下架套餐引用 | 提示后允许，发布时解除引用 |
| 平台菜单被角色引用 | 展示受影响角色，确认后允许 |
| 无引用 | 二次确认后允许 |

- 删除后标记"待删除"，发布前可恢复；发布时服务端重新校验。
- 尚未发布过的新菜单可直接移除。
- 发布后软删除，进入回收站；恢复后默认停用，不自动加回套餐。

## 5. 套餐管理

### 5.1 配置方式
- 矩阵编辑：行为菜单，列为套餐。支持目录全选、只看差异、复制为草稿套餐。
- 套餐与菜单为多对多关系，默认不继承。
- 建议支持"主套餐 + 增购包"，可见菜单取并集（待确认）。
- 套餐只决定是否包含菜单，不影响顺序。
- 新菜单默认不属于任何套餐；建议套餐只能引用已发布菜单。
- 目录无需单独授权，有可见子菜单即显示。

### 5.2 状态流转

```text
未发布 ──发布──▶ 已发布 ──下架──▶ 已下架
   │               ▲                 │
   └─删除          └────重新上架──────┘
```

| 操作 | 未发布 | 已发布 | 已下架 |
|---|---|---|---|
| 改名 | ✓ | ✗ | ✗ |
| 修改菜单 | ✓ | ✓（需发布变更） | ✗ |
| 删除套餐 | ✓ | ✗ | ✗ |
| 状态操作 | 发布 | 下架 | 重新上架 |
| 新企业订购 | ✗ | ✓ | ✗ |
| 存量企业使用 | 无存量 | ✓ | ✓ |

### 5.3 规则
- 仅从未发布过的套餐可改名；名称必填、唯一（含已下架）。
- 发布前提示：发布后名称不可修改。
- 按单个套餐发布；有待发布变更时，先发布或放弃，再下架。
- 下架仅停止新订购，存量企业的菜单权限和有效期不变。
- 全局停用菜单仍对存量生效，操作前须列出受影响套餐（含已下架）。

### 5.4 与企业角色联动（建议）

| 场景 | 处理 |
|---|---|
| 套餐新增菜单 | 默认仅授予企业管理员 |
| 菜单移出套餐或企业降级 | 立即不可访问，保留授权记录 |
| 重新升级 | 恢复原授权 |

## 6. 权限计算

- **平台成员**：已发布且启用的平台菜单 ∩ 角色授权并集
- **企业成员**：已发布且启用的租户菜单 ∩ 有效订阅套餐并集 ∩ 角色授权并集

菜单隐藏不代替鉴权，路由和接口须由服务端单独校验。

## 7. 审计日志

### 7.1 记录范围
所有用户变更操作，包括草稿操作和失败操作：
- 菜单：新增、修改、排序、移动、启停、删除、恢复、撤销、放弃、发布、回滚。
- 套餐：新建、复制、改名、菜单配置、发布、放弃变更、上下架、删除。
- 其他：订阅、成员、角色、授权变更，日志导出。

### 7.2 记录字段
操作人（ID、姓名快照、角色、所属企业）、时间、IP、设备、模块、动作、对象（ID、名称快照）、变更前后值、结果、失败原因、请求 ID、批次号、影响范围。

### 7.3 要求
- 服务端生成，只能追加，系统内不可修改或删除。
- 与业务变更同事务写入，或使用事务性消息保证不丢失。
- 敏感信息脱敏。
- 支持按时间、操作人、模块、动作、对象、结果筛选，可查看前后对比。
- 查看和导出单独授权；企业侧仅能查看本企业记录。

## 8. 核心数据模型

| 表 | 关键字段 |
|---|---|
| menu | id, code, scope, parent_id, type, name, icon, path, permission_key, sort, status, is_system, is_required, deleted_at |
| menu_draft | menu_id, 变更内容, base_version, updated_by |
| package | id, code, name, type, status, published_at, delisted_at, version |
| package_menu | package_id, menu_id（线上配置） |
| package_menu_draft | package_id, menu_id（待发布配置） |
| tenant_package | tenant_id, package_id, start_at, end_at |
| role_menu | role_id, menu_id |
| audit_log | 见 7.2 |

套餐状态取值：`draft`、`published`、`delisted`。以上业务规则均须由服务端校验。

## 9. 待确认事项

| 事项 | 建议默认值 |
|---|---|
| 套餐菜单变更是否立即影响存量企业 | 立即生效；若需保留老权益，引入套餐版本 |
| 下架套餐能否续费、增加席位 | 允许 |
| 到期或退订后能否重新购买下架套餐 | 不允许 |
| 下架前的未支付订单 | 有效期内可完成 |
| 企业能否叠加多个套餐 | 一个主套餐 + 多个增购包 |
| 套餐到期如何处理 | 仅保留续费入口 |
| 下架套餐引用的功能如何退役 | 单独设计通知与审批流程 |
| 审计日志留存期限 | 按合规要求确定 |
