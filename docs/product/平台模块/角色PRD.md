
## 授权

认证成功后,系统按用户的角色计算其可访问的资源,并在每次请求时校验;授权遵循“默认拒绝”。

| 编号 | 规则                                                         | 默认值 | 可配置 |
| ---- | ------------------------------------------------------------ | ------ | ------ |
| P-01 | 采用角色授权:权限授予角色,角色分配给用户;一个用户可有多个角色,权限取并集 | —      | 否     |
| P-02 | 权限分四类:菜单、按钮操作、接口、数据范围(全部 / 本部门 / 仅本人 / 自定义规则) | —      | 否     |
| P-03 | 默认拒绝:未被授予的资源一律不可访问                          | —      | 否     |
| P-04 | 每次请求都在服务端校验权限,前端隐藏菜单和按钮只作体验优化,不作为安全手段 | —      | 否     |
| P-05 | 用户的角色或角色的权限变更后,在 5 分钟内对已登录会话生效     | 5 分钟 | 是     |
| P-06 | 无权访问时,接口返回 403,页面提示“无权访问该页面”,并记录审计日志 | —      | 否     |
| P-07 | 超级管理员角色不可删除,系统至少保留 1 个启用的超级管理员     | 1 个   | 否     |

授权相关的操作(分配角色、修改角色权限)也写入审计日志,字段同 R-14。

数据范围有两种设定方式:按部门,即全部、本部门、仅本人;自定义规则,由管理员为角色配置可访问的部门或数据条件。一个角色可配置多条规则,结果取并集。本期授权只做角色模型,不做按用户单独授权。
