| 术语名称        | 英文 / 缩写                           | 定义                                     | 备注                                       |
| ----------- | --------------------------------- | -------------------------------------- | ---------------------------------------- |
| 认证          | Authentication                    | 核验访问者身份是否真实、是否为申报主体本人的过程，回答「你是谁」       | ✅ 区分【鉴权】；认证成功≠有权限访问功能                    |
| 鉴权          | Authorization                     | 在身份确认后，判断该身份是否允许访问指定资源 / 接口，回答「你能做什么」  | 认证前置，鉴权后置；权限模块核心逻辑                       |
| 登录          | Login                             | 用户主动发起、完成身份认证并建立有效会话的操作动作              | 登录是认证的一种交互形态；后台接口鉴权可无登录页（API 调用）         |
| 登出 / 注销登录   | Logout                            | 主动销毁当前有效会话、Token，清除身份凭证                | 区分【账号注销】；登出只是退出会话，不删除账号                  |
| 账号注销        | Account Deactivation              | 销毁用户账号主体数据，账号永久不可使用                    | 高危操作，单独权限，≠登出                            |
| 会话          | Session                           | 服务端维护的一次用户登录上下文，保存身份、登录时间、IP 等信息       | 传统 Cookie-Session 模式；和 JWT 无服务端会话不同      |
| 访问令牌        | Access Token                      | 认证通过后下发的凭证，用于后续接口鉴权                    | 短期有效；过期需刷新，不可单独用于登录                      |
| 刷新令牌        | Refresh Token                     | 用于获取新 Access Token 的长效凭证               | 不参与业务接口鉴权；泄露风险更高，存储策略更严格                 |
| 单点登录        | SSO (Single Sign-On)              | 一次身份认证后，可免密登录多个互信业务系统                  | 本项目对接上游统一身份平台，支持 SAML/OIDC 协议            |
| 多因素认证       | MFA (Multi-Factor Authentication) | 两种及以上独立核验因子组合完成身份认证                    | 因子示例：密码 + 短信验证码 / 密码 + PKI 证书            |
| 双因素认证       | 2FA                               | MFA 的子集，仅使用两种核验因子                      | 项目安全策略：管理员登录强制 2FA                       |
| 一次性验证码      | OTP                               | 单次有效、限时的动态验证码                          | 含 TOTP（时间型，谷歌验证器类）、短信 OTP                |
| PKI 证书认证    | PKI Authentication                | 使用 X.509 数字证书作为身份凭证，由签名服务验签            | 对接 Signing Server+HSM 硬件，用于高安全接口         |
| 签名验签        | Sign & Verify                     | 使用证书私钥生成签名、公钥校验报文完整性与身份                | 属于认证附属能力，≠登录认证                           |
| OAuth2.0    | OAuth 2.0                         | 授权框架协议，本项目用于第三方系统授权接入                  | ⚠️ OAuth2.0 是**授权协议**，不是认证协议；如需认证叠加 OIDC |
| OIDC        | OpenID Connect                    | 基于 OAuth2.0 的身份认证协议，输出 ID Token 标识用户身份 | SSO 对接优先 OIDC                            |
| 身份标识令牌      | ID Token                          | OIDC 下发，承载用户身份信息（sub、姓名等）              | 主要用于身份识别，不用于业务接口鉴权                       |
| 账号锁定        | Account Locked                    | 连续认证失败达到阈值后，账号临时禁止登录                   | 区分【禁用】；锁定支持自动解锁 / 管理员手动解锁                |
| 账号禁用        | Account Disabled                  | 管理员主动冻结账号，永久禁止登录，直到启用                  | 不受失败次数控制；离职用户常用状态                        |
| 静默登出        | Silent Logout                     | 无前端弹窗提示，后台直接销毁会话                       | 触发场景：异地高风险登录、后台强制下线、会话超时                 |
| 强制下线        | Force Logout                      | 管理员主动操作，踢掉用户所有在线会话                     | 审计日志必记录操作人、时间、目标账号                       |
| 会话超时        | Session Timeout                   | 长时间无操作，会话自动失效                          | 区分 Token 过期：会话超时是业务侧策略，Token 过期是凭证本身有效期  |
| 白名单         | IP Whitelist                      | 仅列表内 IP 可访问认证接口 / 登录入口                 | 用于后台管理端、HSM 签名服务内网访问控制                   |
| 密码策略        | Password Policy                   | 系统对密码长度、复杂度、有效期、历史复用限制规则               | 安全配置项，可在认证管理页配置                          |
| 认证审计日志/登录日志 | Login Log                         | 记录所有认证相关事件：登录、登出、认证失败、锁定、MFA 核验、强制下线   | 不可删除，用于安全追溯                              |
| 认证管理员       | Auth Admin                        | 拥有账号解锁、禁用、查看认证审计日志权限的角色                | 不能分配业务数据权限，遵循权限最小化                       |
| 身份源         | Identity Provider / IdP           | 提供用户身份数据、负责认证的外部系统                     | 本项目上游 IdP：统一身份平台                         |
| 服务提供方       | Service Provider / SP             | 当前中后台业务系统，依赖 IdP 完成 SSO 登录             |                                          |
